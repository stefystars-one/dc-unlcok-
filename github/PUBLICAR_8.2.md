# GitHub Releases — Discord Unlock 8.2

Repositório: https://github.com/stefystars-one/dc-unlcok-

Publique uma Release com a tag v8.2 e envie estes assets:
- DiscordUnlock.exe
- DiscordUnlock_Special.exe
- DiscordUnlock_Instalar.ps1
- update-manifest.json

O aplicativo consulta o asset update-manifest.json da Release mais recente do GitHub. Cada executável é validado por SHA-256 antes de ser instalado.
