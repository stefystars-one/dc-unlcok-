Sites de mídia permitidos na galeria

Adicione domínios de sites que fornecem links HTTPS diretos para imagens, GIFs e vídeos. Isso permite cadastrar links desses domínios; busca automática exige uma API própria compatível.

💡 Como pegar o link correto:
• Klipy: Abra a página do GIF no Klipy, clique com o botão direito sobre o GIF e selecione "Copiar endereço da imagem".
• Giphy & Imgur: Pode colar o link da página ou o link direto — o sistema normaliza automaticamente.
• Tenor, Discord & Catbox: Clique com o botão direito na animação e selecione "Copiar endereço da imagem".
• Vídeo: use o link HTTPS direto de um arquivo MP4 ou WebM. O vídeo será reproduzido em loop, sem som.
